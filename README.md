## Features

**Clipboard History**
Keep everything you copy — unlimited history, searchable, always synced via iCloud.

**Quick Paste**
Pop open a floating window to paste any clipboard item into any app without breaking flow.

**Collections & Boards**
Organize your most-used clips into boards for instant access.

**Snippets**
Store reusable text, templates, and boilerplate with optional hotkeys for instant paste.

**QR Code Scanner**
Scan QR codes directly from the menu bar.

**Paste Stack**
Queue up a series of items and paste them one by one in sequence.

**Text Selection Tools**
Instantly copy, transform, and act on selected text from any app.

**iCloud Sync**
Your clipboard history syncs seamlessly across Mac, iPhone, and iPad.

## Install

**Direct Download (Mac)**
```
https://awesomecopy.app
```

**Homebrew (Stable)**
```sh
brew install kindparkllc/tap/awesome-copy
```

**Homebrew (Beta)**
```sh
brew install kindparkllc/tap/awesome-copy-beta
```

**App Store**
Available for Mac, iPhone, and iPad on the [App Store](https://apps.apple.com/us/app/awesome-copy-2/id6761966640).
